# КотоБлог — прототип интерфейса

Кликабельный макет мобильной игры для детей 7–11 лет: виртуальный питомец
кот-блогер, на котором отрабатывается распределение бюджета на
**обязательное / сбережения / хотелки**.

Ориентация — **альбомная**, экран 844×390. Это не повёрнутый портрет:
навигация вынесена в левую рейку, а содержимое каждого экрана разложено
в колонки, чтобы ключевое было видно без прокрутки.

## Как открыть

Прототип — статический сайт без сборки. Достаточно открыть `index.html`
в браузере. Если Manrope не подтянулся (нет интернета), подставится Inter
или системный шрифт — вёрстка не поедет.

Локальный сервер, если нужен:

```bash
npx --yes serve prototype -l 4321
```

## Визуальная система

Минималистичная и воздушная: бумажный фон, белые поверхности **без обводок** —
их разделяют отступы и мягкая тень, а не линии. Один акцентный цвет. Цвет несёт
смысл, а не украшает: три кошелька — единственное постоянное цветное пятно.

**Экран питомца устроен иначе, чем остальные.** Комната занимает весь кадр
844×390 — это сцена, а не карточка с котом. Интерфейс лежит поверх неё на
матовом стекле (`backdrop-filter`) и своего фона не имеет: комната
просматривается насквозь. HUD собран по краям — рейка слева, показатели и
кнопки ухода справа, серия дней внизу — центр сцены остаётся свободным.

| Роль | Значение |
|---|---|
| Фон / поверхность | `#F7F5F1` · `#FFFFFF` |
| Границы | `#E9E5DE` — везде 1 px, тени только у выезжающего меню |
| Акцент | `#6C5CE7` |
| 🔵 Нужное | `#3B82F6` — обязательные траты |
| 🟢 Копилка | `#0FB47F` — сбережения |
| 🩷 Хотелки | `#F2506B` — необязательные траты |
| Шрифт | Manrope (Inter → системный в запасе) |
| Иконки | 54 контурных SVG-символа в спрайте, штрих 1.8 |

Эмодзи в интерфейсе не используются — весь иконочный набор нарисован
в `index.html` как `<symbol>` и подключается через `<use href="#i-...">`.

## Что внутри

```
prototype/
  index.html        оболочка сайта + SVG-спрайт со всеми иконками
  css/style.css     тёмная витрина вокруг телефона
  css/app-ui.css    UI-кит приложения: сцена и HUD, рейка, меню, колоночная сетка
  js/screens.js     13 экранов, персонаж, сова-наставник и комната в inline-SVG
  js/app.js         навигация, галерея, сценарий, меню, связанные ползунки бюджета
```

## Три режима просмотра

| Режим | Зачем |
|---|---|
| **Экран** | Один макет в корпусе устройства + пояснение справа: какие решения приняты и чему экран учит |
| **Все экраны** | Все 13 макетов сеткой — общий обзор для защиты проекта |
| **Сценарий** | Главный путь одной сессии: от входа до родительской сводки |

Экраны переключаются кликом по рейке слева, стрелками `←` / `→`,
навигацией внутри телефона и кнопками внутри самих экранов.
Корпус устройства сам ужимается под ширину окна.

## Навигация в приложении

- **Свёрнутая рейка, 66 px** — пять основных разделов иконками без подписей,
  активный помечен полоской слева, внизу — достижения и родительский вход.
- **Выдвижное меню по кнопке-бургеру** — 356 px, выезжает поверх с затемнением
  фона. Разделы сгруппированы в две колонки: Игра · Деньги · Обучение · Ещё.
  У денежных пунктов вместо иконки — цветная точка кошелька и текущий остаток.
- На экранах «Итог съёмки», «Распределение дохода» и «Кабинет родителя»
  навигации нет намеренно: из первых двух выход только вперёд, третий —
  не часть детского приложения.

## Что интерактивно

Игровой логики, экономики и бэкенда нет — состояние нигде не сохраняется.
Кликабельно ровно то, что нужно для демонстрации идеи:

- **меню** — открывается бургером в рейке, закрывается крестиком или тапом по затемнению;
- переходы между экранами (рейка, меню, кнопки внутри экранов);
- вкладки в магазине и переключатели в настройках;
- **ползунки на экране бюджета** — связаны между собой: сумма всегда равна
  доходу (252), проценты, заливка ползунка и полоса пропорций пересчитываются.
  Если недодать на обязательное, подпись под ползунком меняется на
  предупреждение с точной нехваткой, а кнопка подтверждения блокируется.

Все числа, состояния и «купленные» предметы — заранее заданные значения макета.
